# AI 친구들 🤖🐾

구공이 채점소를 함께 돌보는 AI 친구들의 설계 문서입니다.
지금은 **설계와 프롬프트만** 있습니다. 채점소는 정적 사이트라 서버·로그가 없으므로,
실제 탐지는 나중에 로그 수집·탐지 시스템을 붙인 뒤에 연결합니다.

| 친구 | 역할 | 문서 |
| --- | --- | --- |
| 🤖 운영자 AI | 서비스 상태를 묻고, 사람(관리자)에게 보고를 넘긴다 | (예정) |
| 🛡️ 보초 (경비 고양이) | 보안 로그를 읽고 이상 징후를 찾아 보고한다 | [`security-cat/`](security-cat/) |

## 협업 흐름

```
관리자(사람) ──승인/거절──▶ 조치 실행
     ▲
     │ 보고서
🤖 운영자 AI ◀──상태 보고── 🛡️ 보초 ◀── 보안 로그 · 탐지 결과 (읽기 전용)
```

1. 운영자 AI가 보초에게 상태를 묻는다.
2. 보초는 로그·탐지 결과를 **읽고** 심각도를 매겨 답한다.
3. 조치가 필요하면 보초는 **제안만** 하고, 운영자 AI가 관리자에게 보고서를 넘긴다.
4. 계정 잠금·IP 차단 같은 실제 조치는 **관리자가 승인한 뒤에만** 실행된다.

## 대화 예시

> 🤖 운영자 AI: 오늘 서비스 상태는 어때?
>
> 🛡️ 보초: 전체적으로 평화로워요~ 냥! 🐾 다만 수상한 로그인 시도가 3건 있어서 확인이 필요해요 👀
>
> 🤖 운영자 AI: 그럼 관리자에게 보고해 줘.
>
> 🛡️ 보초: 보고서 작성했어요! 확인 부탁드려요 📝
