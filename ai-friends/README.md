# AI 친구들 🤖🐾

구공이 채점소를 함께 돌보는 AI 친구들의 설계 문서입니다.
보안전문 구공이는 [`security-cat/server/`](security-cat/server/)에서 **실제로 돌아갑니다** (글·채팅·이미지 검열, 로그 분석, 코드 점검).
집사는 아직 설계와 프롬프트만 있어요.

| 친구 | 역할 | 문서 |
| --- | --- | --- |
| 🤖 집사 (운영자 AI) | 서비스 상태를 묻고, 사람(관리자)에게 보고와 승인 요청을 넘긴다 | [`operator/`](operator/) |
| 🛡️ 보안전문 구공이 | 보안 로그를 읽고 이상 징후를 찾아 보고한다 | [`security-cat/`](security-cat/) |

## 협업 흐름

```
관리자(사람) ──승인/거절──▶ 조치 실행
     ▲
     │ 보고서
🤖 집사(운영자) ◀──상태 보고── 🛡️ 보안전문 구공이 ◀── 보안 로그 · 탐지 결과 (읽기 전용)
```

1. 운영자 AI가 보안전문 구공이에게 상태를 묻는다.
2. 보안전문 구공이는 로그·탐지 결과를 **읽고** 심각도를 매겨 답한다.
3. 조치가 필요하면 보안전문 구공이는 **제안만** 하고, 운영자 AI가 관리자에게 보고서를 넘긴다.
4. 계정 잠금·IP 차단 같은 실제 조치는 **관리자가 승인한 뒤에만** 실행된다.

## 대화 예시

> 🤖 운영자 AI: 오늘 서비스 상태는 어때?
>
> 🛡️ 보안전문 구공이: 전체적으로 평화로워요~ 냥! 🐾 다만 수상한 로그인 시도가 3건 있어서 확인이 필요해요 👀
>
> 🤖 운영자 AI: 그럼 관리자에게 보고해 줘.
>
> 🛡️ 보안전문 구공이: 보고서 작성했어요! 확인 부탁드려요 📝
