# 구공이 90점 채점소 🐾

고양이 **구공이**가 되어 집 안과 골목을 직접 걸어 다니며 인간들을 채점하는 2D 사이드뷰 웹 미니게임입니다.
빌드 도구 없이 `index.html`만 열면 바로 실행되는 정적 사이트라 GitHub Pages·정적 CDN 어디서든 그대로 돌아갑니다.

## 플레이 방법

1. **심사 시작** — 하루에 집 안 2명 + 골목 2명, 3일 동안 12명을 심사합니다.
2. 무대의 **왼쪽·오른쪽을 누르고 있으면** 구공이가 그쪽으로 걸어갑니다. 배경이 따라 흐르고, 인간이 다가와 서면 이름표와 말풍선이 뜹니다.
3. 인간에게 **가까이 가면** 아래 관찰 버튼이 열립니다. **냄새 · 눈빛 · 행동**을 살피세요. 관찰 한 번에 2초가 흐릅니다.
4. 시간이 다 가기 전에 팻말을 들어 판정합니다.
   - **+ 합격** — 밥 시간을 지킨다, 동족을 예뻐한다, 조용히 간식을 바친다, 사냥놀이를 해준다
   - **− 감점** — 자는 데 손댄다, 큰 소리를 낸다, 빈손으로 온다, 츄르를 아낀다, 꼬리를 밟는다
   - **90 냉정** — 애정은 있는데 간식이 없는 인간, 말과 손이 다른 인간처럼 +도 −도 아닌 경우
5. 판정하면 **인간 머리 위에 점수가 뜹니다.** 맞히면 `+100 냥력`(연속 보너스 최대 +100), 틀리면 40.
6. 집 안 두 명을 마치면 구공이가 문가로 걸어가 **골목으로** 넘어갑니다. 12명을 다 심사하면 **최종 등급**이 나오고, 최고 기록은 브라우저에 저장됩니다.

키보드로도 됩니다: `←/→` 걷기 · `1/2/3` 관찰 · `A/S/D` 판정 · `Enter` 다음.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (타이틀 · 무대 · 조작부 · 하루 정산 · 최종) |
| `style.css` | 픽셀 감성 UI, 모바일 세로 화면 최적화 |
| `game.js` | 사이드뷰 엔진 (카메라·패럴랙스·인간 상태·판정·Web Audio 효과음) |
| `data.js` | 인간 12명의 관찰 단서 · 심사평 · 정답 해설 · 장면 배치 |
| `assets/people/` | 인간 캐릭터 픽셀 아트 12종 |
| `assets/gugoong.png` | 구공이 (원본 `downloads/gugoong-character.png`에서 배경 제거) |

## 만든 방식

- 배경(집 안 거실 · 골목)은 `game.js`의 캔버스(240×135)에 직접 그리는 픽셀 아트이며, 카메라가 구공이를 따라가고 건물 층은 서로 다른 속도로 흐릅니다.
- 인간 12명은 같은 화풍 문장(굵은 갈색 외곽선·한정 팔레트·왼쪽 위 광원·옆모습)으로 생성한 픽셀 아트 이미지를 배경 제거·축소해 스프라이트로 사용했습니다. 7종을 기본으로 만들고 색·소품만 바꾼 변형 5종을 더해 12명을 채웠습니다.
- 소리: Web Audio API로 합성한 효과음 (오른쪽 위 🔊 버튼으로 끄기, 설정 저장)
