# 구공이 90점 채점소 🐾

고양이 **구공이**가 되어 집 안과 골목을 직접 걸어 다니며 인간들을 채점하는 2D 사이드뷰 웹 미니게임입니다.
빌드 도구 없이 `index.html`만 열면 바로 실행되는 정적 사이트라 GitHub Pages·정적 CDN 어디서든 그대로 돌아갑니다.

## 플레이 방법

1. **심사 시작** — 하루에 집 안 2명 + 골목 2명, 3일 동안 12명을 심사합니다.
2. 무대의 **왼쪽·오른쪽을 누르고 있으면** 구공이가 그쪽으로 걸어갑니다. 배경이 따라 흐르고, 인간이 다가와 서면 이름표와 말풍선이 뜹니다.
3. 인간에게 **가까이 가면** 아래 관찰 버튼이 열립니다. **냄새 · 눈빛 · 행동**을 살피세요. 관찰 한 번에 2초가 흐릅니다.
4. 시간이 다 가기 전에 팻말을 들어 판정합니다.
   - **+ 합격** — 밥 시간을 지킨다, 동족을 예뻐한다, 조용히 간식을 바친다, 사냥놀이를 해준다
   - **− 감점** — 자는 데 손댄다, 큰 소리를 낸다, 빈손으로 온다, 츄르를 아낀다, 꼬리를 밟는다
   - **90 냉정** — 애정은 있는데 간식이 없는 인간, 말과 손이 다른 인간처럼 +도 −도 아닌 경우
5. 판정하면 **인간 머리 위에 점수가 뜹니다.** 맞히면 `+100 냥력`(연속 보너스 최대 +100), 틀리면 40.
6. 집 안 두 명을 마치면 구공이가 문가로 걸어가 **골목으로** 넘어갑니다. 12명을 다 심사하면 **최종 등급**이 나오고, 최고 기록은 브라우저에 저장됩니다.

키보드로도 됩니다: `←/→` 걷기 · `1/2/3` 관찰 · `A/S/D` 판정 · `Enter` 다음.

## 미니게임: 햄찌 씨앗 비행

`minigame/index.html` — 채점소와 별개인 독립 미니게임. 프로펠러 모자를 쓴 햄스터가 하늘을 날며 해바라기씨를 모은다.

- 누르고 있으면 위로, 떼면 아래로 (키보드 `Space`/`↑`). 🌰 씨앗 +1 · 🌻 해바라기 +10
- 까마귀(씨앗 5개를 뺏어감)·먹구름·연(줄이 땅까지 이어져 있어 위로 넘어가야 함)에 닿거나 땅에 떨어지면 목숨 −1(떨어지면 통 튀어오름), 목숨 3개
- 씨앗 25개로 볼주머니가 가득 차면 **필살기**(오른쪽 아래 🌻 버튼 · `X`): 3초 무적, 씨앗 부채꼴 연사, 화면의 장애물을 씨앗으로 바꾸고 보스 체력 15% 즉시 감소. 쓰고 나면 12초 재충전(버튼에 남은 시간 표시)
- 보스마다 **최종 공격**: 붉은 기운과 경고 뒤에 꽃가루 벽(나비, 빈틈 넓음) · 깃털 벽 3연발(까마귀) · 별빛 고리 3연발(부엉이) · 한 줄만 남기고 화면을 덮는 천둥(먹구름 대장). 초록 빈틈으로 피하고, 필살기로 끊을 수도 있다
- 난이도 곡선: 1단계는 장애물 25%·먹구름 없음·까마귀가 햄찌를 노리지 않음 → 2단계 35% → 3단계 45%(부엉이 고리 빈틈 좁게) → 4단계 55%(연+까마귀 조합). 단계마다 조금씩 빨라짐
- 먹구름 대장 **2페이즈**(체력 30% 아래): 화면이 어두워지고 번개+물방울을 같이 쏜다. **대폭풍**(천둥 5연발, 안전 줄이 위아래로 크게 이동)을 버티면 3초 동안 지쳐서 무방비가 되고, 이때 껍질은 2배·필살기는 25% 피해
- 단계마다 배경이 바뀐다: 해바라기 들판 → 노을 언덕 → 별밤 숲 → 천둥 구름길
- 단계 끝마다 보스(꽃밭 나비 16 → 대왕 까마귀 38 → 밤 부엉이 52 → 먹구름 대장 72, 숫자는 체력). 보스전에선 씨앗 껍질을 자동 발사
- 보스를 이기면 **화해**하고 친구가 되어 선물을 준 뒤 햄찌 뒤를 따라다닌다: 🍯 꿀 방패(나비. 2단계부터 **친구 찬스** 버튼 · `C`로 20초마다 다시 부를 수 있음) · 💎 씨앗 자석(까마귀) · 🌰 필살기 18개로 충전(부엉이) · 🌈 목숨 가득 + 먹구름이 안 아파짐(먹구름 대장)
- 1단계 꽃밭 나비를 이기면 **엔딩 1 컷신**: 그림 세 장(`minigame/assets/ending1-*.jpg`)이 차례로 '쿵' 내려앉으며 나온다. 탭하면 넘어가고, 본 엔딩은 타이틀에 표시
- 먹구름 대장까지 화해하면 다 같이 모이는 **해바라기 파티 엔딩**. 이후 '계속 날기'로 무한 진행(두 바퀴째 보스는 '또 화해')
- 그림은 전부 캔버스로 직접 그렸고 최고 기록은 브라우저에 저장

## 미니게임: 햄찌 틀린 그림 찾기

`spot/index.html` — 햄찌·나비·까마귀·부엉이가 나오는 장면을 매판 새로 그려서, 위아래 두 그림에서 다른 곳을 찾는다.

- 다른 곳을 위·아래 어느 그림에서든 톡 누르면 +100점, 단계를 다 찾으면 남은 시간 × 10 보너스
- 아무 데나 누르면 시간 −5초, 힌트는 한 판에 3번
- 1단계는 5곳(없어짐·색 바뀜처럼 눈에 띄는 것만), 단계마다 한 곳씩 늘고(최대 8곳) 2단계부터 크기·방향·까마귀 뒤집기·씨앗 기울기·버섯 점 개수 같은 미묘한 변화가 섞인다. 제한 시간은 62초에서 단계마다 4초씩 줄어 최소 40초
- 배경은 낮 → 노을 → 밤 순서로 돌고, 최고 점수는 브라우저에 저장

## 만든 방식

- 배경(집 안 거실 · 골목)은 `game.js`의 논리 좌표계(240×135)로 그립니다. 캔버스 내부 해상도는 무대 크기 × `devicePixelRatio`에 맞춰 자동으로 잡히므로(아이폰 레티나에서 1368×770 전후) 배경과 캐릭터가 확대돼도 뭉개지지 않습니다.
- 인간 12명은 고해상도 일러스트(할머니·청재킷 남자·올리브 니트 여자·노란 가방 아이·택배 기사)에서 배경을 제거해 스프라이트로 쓰고, 옷 색만 바꾼 변형을 더해 12명을 채웠습니다. 아이는 어른 키의 70%로 그려집니다.
- 무대는 240×135 논리 좌표계이고, 사람은 76px(무대 높이의 56%), 구공이는 34px로 그립니다.
- 배경(집 안·골목)은 바닥선을 고정한 채 1.45배 확대해 그려 사람·구공이와 비율을 맞춥니다.
- 스프라이트는 440px 높이의 투명 PNG라 76px(논리)로 줄여 그려도 윤곽이 살아 있습니다.
- 소리: Web Audio API로 합성한 효과음 (오른쪽 위 🔊 버튼으로 끄기, 설정 저장)
