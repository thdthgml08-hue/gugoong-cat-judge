# 구공이 90점 채점소 🐾

고양이 **구공이**가 되어 집사와 지나가는 인간들을 채점하는 2D 웹 미니게임입니다.
빌드 도구 없이 `index.html`만 열면 바로 실행되는 정적 사이트라 GitHub Pages에 그대로 올릴 수 있습니다.

## 플레이 방법

1. **심사 시작** — 3일 동안 하루 4명, 모두 12명의 인간을 심사합니다.
2. 인간이 골목에 도착하면 **냄새 · 눈빛 · 행동**을 관찰합니다. 관찰 한 번에 2초가 흐릅니다.
3. 시간이 다 가기 전에 팻말을 들어 판정합니다.
   - **+ 합격** — 밥 시간을 지킨다, 동족을 예뻐한다, 조용히 간식을 바친다, 사냥놀이를 해준다
   - **− 감점** — 자는 데 손댄다, 큰 소리를 낸다, 빈손으로 온다, 츄르를 아낀다, 꼬리를 밟는다
   - **90 냉정** — 애정은 있는데 간식이 없는 인간, 말과 손이 다른 인간처럼 +도 −도 아닌 경우
4. 맞히면 `+100 냥력`(연속 정답이면 보너스 최대 +100), 틀리면 `+40`. 인간을 놓치면 0.
5. 12명을 다 심사하면 **최종 등급**이 나옵니다. 최고 기록은 브라우저에 저장됩니다.

팻말은 화면 아래 버튼을 눌러도 되고, 키보드로는 `1/2/3`(관찰) · `+/−/9`(판정) · `Enter`(다음)로도 조작할 수 있습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (타이틀 · 게임 · 하루 정산 · 최종) |
| `style.css` | 픽셀 감성 UI, 모바일 세로 화면 최적화 |
| `game.js` | 게임 엔진 (상태 전이 · 캔버스 장면 · Web Audio 효과음) |
| `data.js` | 심사 대상 인간 12명의 관찰 단서 · 심사평 · 정답 해설 |
| `assets/` | 구공이 픽셀 아트, 픽셀 폰트(Galmuri11, SIL OFL) |

## 실행

```bash
# 그냥 열기
open index.html

# 또는 로컬 서버
python3 -m http.server 8000
```

## 만든 방식

- 캐릭터: 손그림 픽셀 아트 `assets/gugoong.png` (원본 `downloads/gugoong-character.png`에서 배경 제거)
- 배경·인간: `game.js`의 캔버스(240×160)에 직접 그리는 픽셀 스프라이트
- 소리: Web Audio API로 합성한 미니 효과음 (오른쪽 위 🔊 버튼으로 끄기, 설정 저장)
- 폰트: [Galmuri11](https://github.com/quiple/galmuri) — SIL Open Font License 1.1 (`assets/fonts/LICENSE-OFL.md`)
