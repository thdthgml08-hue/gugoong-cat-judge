# 구공이 PC 검사기 — 인수인계 문서

이 문서는 **클로드 코드(사용자 PC에서 실행·수정)** 와 **챗GPT(코드 검토·안내 문구 검수)** 에게 넘기는 문서다.
읽는 사람이 이 폴더만 받아서 이어서 일할 수 있게 썼다.

- 작성: 2026-11-26, 쿠아(피클)
- 프로그램 버전: `gugoong_pc.py` v0.1.0 (1차 데모)
- 사용자: 송소희 (윈도우 노트북, 파이썬 초보)
- 짝이 되는 웹앱: <https://thdthgml08-hue.github.io/gugoong-cat-judge/security/> (저장소 `thdthgml08-hue/gugoong-cat-judge`의 `security/`)

## 0. 한눈에

| 항목 | 내용 |
|---|---|
| 목적 | 구공이(902, 침착하고 다정한 경비원 친구)가 사용자의 PC를 **같이** 검사해 주는 데모 |
| 방식 | 자체 백신 엔진을 만들지 않는다. **윈도우 디펜더(MpCmdRun.exe)를 빌려 쓴다** |
| 검증 상태 | 리눅스에서 `py_compile` + `--dry-run`만 통과. **윈도우 실제 실행은 미검증** |
| 배포 형태 | 단일 `gugoong_pc.py` (표준 라이브러리만), 문서 2개 |
| 다음 단계 | 2호기: 안드로이드 앱(문자 알림 선경고·번호 차단) |

### 왜 엔진을 직접 만들지 않나

보안 회사들이 수십 년 걸려 만드는 영역이고, 어설픈 엔진이 "괜찮아요"라고 잘못 안심시키는 것이 가장 위험하다.
사용자·클로드·챗GPT가 합의한 결론이므로 이 방향을 바꾸지 말 것.
구공이의 역할은 ① 검사 실행을 돕고 ② 결과를 다정하게 설명하는 것뿐이다.

## 1. 현재 구현 범위

### 되는 것

- `MpCmdRun.exe` 자동 탐색
  - `%ProgramData%\Microsoft\Windows Defender\Platform\<버전>\MpCmdRun.exe` (최신 버전 우선)
  - `%ProgramFiles%\Windows Defender\MpCmdRun.exe`
  - `PATH`의 `MpCmdRun.exe`
  - 상태 점검에서 읽은 `AMServiceVersion`을 힌트로 해당 버전 폴더를 먼저 본다.
- 빠른 검사(`-Scan -ScanType 1`), 전체 검사(`2`), 폴더/파일 지정 검사(`3 -File "<경로>"`)
- 검사 중 경과 시간 안내(20초 → 2분 뒤 60초 간격), Ctrl+C 취소, 종료 코드 해석
- 상태 점검: `Get-MpComputerStatus`(실시간 보호·클라우드 보호·사전 버전/나이·마지막 검사·변조 방지·실행 모드),
  `Get-MpThreatDetection` + `Get-MpThreat`(최근 위협의 날짜·이름·조치 상태), `Get-NetFirewallProfile`(방화벽),
  `root/SecurityCenter2`의 등록 백신 이름
- 사전 업데이트(`-SignatureUpdate`)
- 관리자 권한 확인. 없으면 안내만 하고 **권한 상승을 시도하지 않는다**. 상태 점검은 허용.
- 윈도우가 아니면 안내 후 종료(코드 4)
- `--dry-run`: 리눅스/맥에서도 전체 화면 예시 출력
- 모든 출력은 한국어 반말, 구공이 말투

### 일부러 안 하는 것

- 파일 삭제·격리·복원·허용 (디펜더가 한다. `Remove-MpThreat`, `-Restore`, `Set-MpPreference` 쓰기 금지)
- 파일 업로드·외부 전송·VirusTotal 조회 (서버와 API 키가 필요하므로 범위 밖)
- 결과 저장/로그 파일 (개인정보 최소화)
- 관리자 권한 자동 상승(UAC), 서비스/예약작업/시작프로그램 등록
- 실시간 감시, 레지스트리·설정 변경

## 2. 파일과 함수 지도

```
gugoong-pc/
  gugoong_pc.py    # 전부 여기 (단일 파일 유지)
  README.md        # 사용자용 설명서
  handover.md      # 이 문서
```

`gugoong_pc.py` 주요 지점:

| 위치 | 역할 | 수정 시 주의 |
|---|---|---|
| `SCAN_TIMEOUTS` | 검사별 감시 시간 | 전체 검사 4시간. 늘리면 사용자가 멈출 수단(Ctrl+C) 안내 유지 |
| `say()` | 콘솔 출력 | cp949 콘솔에서 이모지 깨짐 방지용 fallback 있음 |
| `setup_console()` | UTF-8 콘솔 설정 | 지우면 한글 깨질 수 있음 |
| `is_admin()` | `shell32.IsUserAnAdmin` | 여기서 권한 상승 시도 금지 |
| `find_mpcmdrun()` | 검사 도구 탐색 | 우선순위 주석 참고. 경로를 새로 추가하면 README도 갱신 |
| `STATUS_BODY` | PowerShell 상태 수집 스크립트 | **PowerShell 5.1 문법**이어야 함. 결과는 `ConvertTo-Json` |
| `RECENT_DETECTION_BODY` | 검사 후 신규 탐지 확인 | `{since}` 치환. 검사 시작 2분 전부터 조회 |
| `run_powershell_json()` | PowerShell 실행 + JSON 수신 | 임시 폴더 파일로 받아 인코딩 문제 회피, `finally`에서 삭제 |
| `render_status()` | 상태 점검 화면 | 문구 수정 시 "단정 금지" 규칙 확인 |
| `do_scan()` | 검사 실행 + 결과 | 종료 코드 0의 두 가지 의미를 반드시 유지 |
| `_run_streaming()` | 진행률·취소·타임아웃 | `proc.kill()` 후 `wait()`. 취소·타임아웃 뒤 `-Cancel`도 보낸다 |
| `get_recent_detections()` | 신규 탐지 조회 | 실패해도 검사 결과는 보여 줘야 함 |
| `render_scan_result()` | 결과 문구 | 코드 0/2/오류 3갈래 |
| `do_signature_update()` | 사전 업데이트 | 관리자 필요 |
| `menu_loop()` | 메뉴 | 질문은 한 번에 하나 |
| `dry_run()` | 화면 예시 | **문구를 고치면 여기 예시도 같이** |
| `main()` | 인자·분기 | 종료 코드 규칙 유지 |

### 종료 코드

| 코드 | 뜻 |
|---|---|
| 0 | 정상 (검사 완료·상태 점검·사용자 종료) |
| 1 | 실행 실패(도구 없음, 경로 오류, 검사 오류, 취소) |
| 2 | 검사에서 디펜더가 "조치 필요"를 알림 (`MpCmdRun` 코드 2) |
| 3 | 관리자 권한 필요 |
| 4 | 윈도우 아님 |

## 4. 윈도우에서 반드시 확인할 테스트

> 기준: 사용자 노트북(윈도우 10/11, 디펜더 사용). 아래를 통과해야 "윈도우 검증됨"이라고 말할 수 있다.
> 테스트 전에 사용자에게 물어보고, **디펜더 설정을 끄거나 바꾸지 말 것.** 꺼진 상태 테스트는 VM/Windows Sandbox에서.

| # | 테스트 | 방법 | 기대 결과 | 통과 기준 |
|---|---|---|---|---|
| T1 | 문법·예시 | `python -m py_compile` / `--dry-run` | 오류 없음, 예시 11개 섹션 | 리눅스와 같은 출력 |
| T2 | 첫 실행 | 탐색기에서 `python gugoong_pc.py` (권한 없이) | 인사 + 관리자 안내 + 메뉴, 1·2·3·5 차단 | 강제 UAC 없음, 4번은 동작 |
| T3 | 상태 점검 | 관리자 PowerShell `--status` | 디펜더·실시간·사전·검사 시각·방화벽·위협 기록 | 값이 실제 `Get-MpComputerStatus`와 일치, 오류 없음 |
| T4 | 빠른 검사 | `--quick` | 진행 안내 후 결과 | 코드 0 → "걸린 게 없었어"(또는 신규 탐지 시 조치 문구), 시간 표시 |

| T13 | 콘솔 한글 | cmd(구 콘솔)와 Windows Terminal 각각 | 한글 정상, 이모지는 '?' 가능 | 깨진 글자 없음 |
| T14 | exe 빌드 | `pyinstaller --onefile --name gugoong-pc gugoong_pc.py` | `dist\gugoong-pc.exe` 실행 | 관리자 실행 시 T3~T5 동작 |
| T15 | 두 번 실행 | 검사 중 새 창에서 또 검사 | 두 번째는 친절한 오류/대기 | 크래시 없음 |

### (선택) EICAR 테스트

실제 바이러스가 아닌 **백신 테스트용 표준 문자열**로 탐지 경로를 확인할 수 있다.
다만 회사 PC나 남의 PC에서는 하지 말고, **사용자 동의를 받은 테스트 폴더**에서만.

1. 테스트 폴더를 하나 만든다.
2. 아래 문자열만 들어 있는 `eicar.com.txt` 를 만든다(줄바꿈 없이).
   ```
   X5O!P%@AP[4\PZX54(P^)7CC)7}$EICAR-STANDARD-ANTIVIRUS-TEST-FILE!$H+H*
   ```
3. 실시간 보호가 켜져 있으면 저장 즉시 잡혀 파일이 사라질 수 있다. 그래도 `--folder` 로 그 폴더를 검사해
   "검사 중에 걸린 항목이 기록에 남아 있어 / 보호 기록 확인" 문구가 나오는지 본다.
4. 테스트 후 파일과 보호 기록을 사용자와 함께 정리한다.

> EICAR는 `Get-MpThreatDetection`에 기록을 남긴다. 실제 사용자 PC에서 남기고 싶지 않으면 VM에서 할 것.

## 5. 수정할 때 지켜야 할 제약 (하드 룰)

1. **표준 라이브러리만.** 새 패키지가 필요하면 먼저 사용자에게 물어본다. (`requirements.txt` 금지)
2. **단일 파일 유지.** 모듈 분리하지 않는다. 사용자가 파일 하나를 복사해 쓰고 있다.
3. **자체 검사 엔진·시그니처 DB를 만들지 않는다.** 디펜더를 빌려 쓰는 구조를 유지한다.
4. **"안전해"라고 단정하지 않는다.**
   - 허용: "지금은 발견된 게 없어", "이번에 검사한 곳에서는"
   - 금지: "안전해", "걱정 없어", "바이러스 없어", "완벽해"
   - 종료 코드 0은 "발견 없음" **또는** "발견 후 조치 완료"라는 사실을 유지한다.
5. **파일을 직접 지우·격리·복원·허용하지 않는다.** `Remove-MpThreat`, `-Restore`, `-DisableRemediation`,
   `Set-MpPreference`(쓰기), `Remove-Item`(사용자 파일) 금지. 안내만 한다.
6. **권한 상승을 시도하지 않는다.** UAC 재실행, 관리자 매니페스트, `runas` 금지. 안내만.
7. **네트워크 요청·업로드·API 키 금지.** 외부 조회가 필요하면 서버를 두고 키를 서버에 둔다(사용자 승인 후).
8. **개인정보 최소화.** 전체 경로·사용자명·도메인 사용자명을 출력하지 않는다. 폴더 이름 정도만.
   기술 메모에도 `C:\Users\<이름>`은 `<사용자>`로 가린다(`_short()`).
9. **질문은 한 번에 하나.** 메뉴에서 여러 개를 한꺼번에 묻지 않는다.
10. **말투.** 반말, 짧은 문장, 다정하고 차분한 경비원. 무서운 단어 남발 금지. 사용자가 겁먹으면 먼저 다독인다.
11. **`--dry-run`은 계속 리눅스에서 돌아가야 한다.** 문구를 고치면 예시도 같이 고친다. 이게 회귀 테스트의 전부다.
12. **윈도우 전용 가정을 깨지 않는다.** `ctypes`, `powershell` 호출은 `IS_WINDOWS`로 감싼다.
13. **예약작업·서비스·시작프로그램을 등록하지 않는다.**

## 6. 알려진 위험과 판단 기록

- **종료 코드 0의 두 가지 의미**
  마이크로소프트 문서: 0 = ① 악성코드 없음 ② 발견했으나 조치 성공. 2 = ① 발견·미조치 ② 사용자 조치 필요 ③ 검사 오류.
  그래서 0만 보고 "발견된 게 없어"라고 하면 틀릴 수 있어, 검사 시작 2분 전 이후의 `Get-MpThreatDetection`을 확인해
  "조치했음"과 "발견 없음"을 구분한다. 이 조회가 실패하면 "처리할 게 남아 있지 않다"는 사실만 말한다.
- **`netsh advfirewall show allprofiles state` 대신 `Get-NetFirewallProfile`**
  요청서에는 netsh가 있었지만, netsh 출력은 윈도우 언어판마다 달라 파싱이 깨진다(한국어: "사용"/"사용 안 함").
  구조화된 `Get-NetFirewallProfile`(Win8+)을 우선 쓰고, 실패하면 "확인 못 했어"로 정직하게 표시한다.
  필요하면 netsh를 보조 수단으로 추가할 수 있으나, 언어별 파싱 테스트가 필요하다.
- **PowerShell 5.1 기준 문법**
  `ConvertTo-Json`, `Get-CimInstance`, `[pscustomobject]`만 사용한다. PS7 전용 문법(`??`, `-Parallel`) 금지.
- **결과를 임시 파일로 받는 이유**
  콘솔 인코딩(cp949) 때문에 한글 JSON이 깨지는 것을 피하려고 `Set-Content -Encoding UTF8` 후 `utf-8-sig`로 읽는다.
  임시 폴더는 `finally`에서 삭제한다.
- **`Get-MpComputerStatus`가 실패하는 경우**
  디펜더 서비스 중지 또는 서드파티 백신이 활성. 이때는 "읽지 못했어 + 직접 확인 경로"만 안내한다(추측 금지).
- **위협 기록을 못 읽은 경우**
  `Get-MpThreatDetection`이 실패하면 `threats_read = false`로 내려와서 "기록 없음"과 구분해 "읽지 못했어"로 표시한다.
  검사 후 신규 탐지 확인(`RECENT_DETECTION_BODY`)은 실패 시 예외를 그대로 올려 "확인 못 함" 경로로 간다.
- **관리자 권한 없이 상태 점검**
  `Get-MpComputerStatus`는 보통 비관리자도 읽히지만 환경에 따라 실패할 수 있다. 실패 문구가 그 경우를 덮는다.
- **PyInstaller 오탐**
  `--onefile` exe가 백신에 오탐되는 사례가 있다. README에 `--onedir`/스크립트 실행 대안을 적어 두었다.

## 7. 다음 단계 메모

### 2호기: 안드로이드 앱 (지금 범위 아님)

- 목표: 문자 알림을 보고 **먼저** 경고, 모르는 번호/스미싱 문자 필터, 통화 차단 안내.
- 웹앱(PWA)으로는 문자·통화에 접근할 수 없어서 앱이 필요하다.
- 안드로이드: `SMS 필터` 역할 또는 `READ_SMS`(정책상 제한), `CallScreeningService`(기본 전화 앱 역할 필요).
  Play 스토어 정책상 SMS/Call Log 권한은 예외 승인이 필요하므로, 배포 전 정책 확인이 선행돼야 한다.
- 아이폰: 서드파티가 문자함·통화를 직접 못 건드린다. `Message Filter Extension`(스팸 분류) 정도가 한계.
- 1호기 웹앱의 판별 문구·규칙(`security/system-prompt.md`)을 앱에서도 재사용한다.

### PC 검사기에 나중에 붙일 수 있는 것

- 윈도우 업데이트 적용 여부, 백업 상태, 오래된 비밀번호 알림 (읽기 전용 점검)
- 결과를 사용자가 원할 때만 텍스트로 저장(기본은 저장 안 함)
- VirusTotal 조회는 **서버 + 서버 측 키**가 전제. 파일 업로드가 아니라 해시 조회부터.

## 8. 클로드 코드 / 챗GPT에게

### 클로드 코드 (사용자 PC)

1. 먼저 `python gugoong_pc.py --dry-run` 으로 현재 화면을 확인한다.
2. `README.md` 3장 방식으로 관리자 실행을 안내하고, **대신 권한을 올리지 않는다.**
3. `4장 테스트 표`를 T1부터 순서대로 돌리고, 결과(통과/실패/메모)를 표에 채워 사용자에게 보여 준다.
4. 코드를 고칠 때는 5장 제약을 지키고, 고친 뒤 `py_compile` + `--dry-run` + 해당 테스트를 다시 돌린다.
5. 실패를 고칠 때 로그를 그대로 붙여 넣지 말고, 사용자 이름·경로를 가린 뒤 공유한다.

### 챗GPT (검토)

- 코드를 실행할 수 없어도 된다. 아래를 중점 검토:
  1. "안전" 단정·과장이 남아 있는지 (문구 전체)
  2. 종료 코드 0/2 해석이 정확한지
  3. 파일 삭제·설정 변경·권한 상승·외부 전송 경로가 없는지
  4. 개인정보(전체 경로·사용자명)가 출력되는 곳이 있는지
  5. 사용자가 겁먹었을 때의 안내 순서(행동 지침 먼저 → 설명)
  6. 초보자가 읽을 때 이해되지 않는 문장
- 문구 수정 제안은 `gugoong_pc.py`의 해당 문자열과 `dry_run()` 예시를 함께 지정해 준다.
