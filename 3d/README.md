# 구공이 3D 장난 탐험판 🐾

2D 「구공이 90점 채점소」와 같은 세계를 **Three.js 3D**로 만든 짧은 탐험 게임입니다.
빌드 도구 없이 `index.html`만 열면 바로 돌아가고, 시점은 **고양이 눈높이 1인칭**이 기본입니다.

- 바로 열기: `3d/index.html`
- 조작: 화면 왼쪽 드래그(조이스틱) · 바닥 톡 누르기 · 오른쪽 드래그(둘러보기) ·
  WASD/방향키 · **Q 관찰** · **Space 장난치기** · **V 1인칭/3인칭**

## 무엇을 하나

1. 크림색 점박이 고양이 **구공이**가 되어 집 안 거실에서 시작합니다. 카메라는 바닥에서 40cm,
   사람과 가구를 올려다보는 낮은 고양이 시점입니다.
2. 문을 지나 골목길까지 걸어 다닙니다. (거실 2명 · 골목 4명 = 사람 6명)
3. 사람 근처에 가면 **👀 관찰 / 🐾 장난치기** 버튼이 뜹니다.
   - **관찰**: 구공이의 엉뚱한 혼잣말이 뜹니다. (사람마다 두 마디씩)
   - **장난치기**: 발목 톡 · 야옹! · 상자(캔) 밀기로 사람을 놀라게 합니다.
     대상은 움찔 몸을 떨고 뒤돌아보며, 머리 위에 `헉!` 같은 말풍선과 반응 대사가 뜹니다.
4. 여섯 명을 한 번씩 다 놀리면 **장난꾸러기 고양이** 완료 카드가 뜹니다.
   (놀린 사람은 한 번 더 놀릴 수 있습니다. 점수는 없고 재미만 있습니다.)

## 1인칭 뷰모델

화면 아래쪽에는 구공이의 몸이 조금 보입니다.
입에 문 **90 팻말의 끝동이**, 두 **앞발**, **수염**, **주둥이**가 코앞에 붙어 있고,
걸으면 발걸음에 맞춰 아주 은은하게 흔들립니다. 장난칠 때는 앞발을 뻗고,
`야옹!` 장난에서는 팻말을 휙 들어 90을 보여 줍니다. (우측 상단 `1인칭/3인칭`으로 3인칭 구경도 가능)

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (타이틀 · HUD · 시점 전환 · 관찰/장난 버튼 · 완료 화면 · 도움말) |
| `style.css` | 크림·브라운 픽셀 감성 UI, 세이프에어리어·가로/세로 대응 |
| `js/main.js` | 게임 루프, 입력(조이스틱·탭·키보드), 1인칭/3인칭 카메라, 관찰·장난 진행 |
| `js/viewmodel.js` | 1인칭 뷰모델 (팻말 끝 · 앞발 · 수염 · 주둥이), 별도 씬으로 렌더 |
| `js/world.js` | 거실·골목길 3D 월드 (창문, 러그, 캣타워, 화분, 문, 우체통, 상자, 가로등, 울타리) |
| `js/cat.js` | 3D 구공이 (점박이 털, 나비넥타이, 90 팻말, 걷기·점프·앞발 장난 애니메이션) |
| `js/npcs.js` | 3D **클레이 피규어** 사람 6명 (둥근 머리·동그란 코·안경·구름 머리·치마·주머니·신발)과 소품 |
| `js/gfx.js` | 재질·캔버스 텍스처(나무·돌바닥·러그·90 팻말·말풍선·발도장·물방울 무늬 등) |
| `js/audio.js` | Web Audio로 합성한 효과음 (야옹 · 툭 · 화들짝 등, 외부 파일 없음) |

## 기술 메모

- Three.js `0.170.0`을 jsDelivr CDN에서 import map으로 불러옵니다. (설치·빌드 없음)
- 사람은 캡슐·구를 겹쳐 만든 무광 클레이 피규어입니다. 손·발목·무릎에 관절 구를 넣어
  구부려도 틈이 벌어지지 않고, 눈·볼터치·안경은 머리 표면에 맞춰 붙였습니다.
- 1인칭 뷰모델은 **월드와 다른 씬/카메라**로 렌더해 벽에 파묻히지 않고 조명도 늘 같습니다.
  위치는 화면 비율(반폭·반높이)에 맞춰 계산해 세로·가로 화면 모두 하단 가장자리에 앉습니다.
- 모든 텍스처는 런타임 캔버스로 그립니다. 브라우저가 화면 밖 캔버스 메모리를 비워도
  텍스처가 검게 변하지 않도록 한 번 이미지로 구워 둡니다.
- 그림자는 1024 해상도 한 장, 픽셀 비율은 최대 2로 제한해 아이폰에서도 가볍게 돕니다.
