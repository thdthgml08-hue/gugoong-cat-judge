# 구공이 3D 미니 탐험판 🐾

2D 「구공이 90점 채점소」와 같은 세계를 **Three.js 3D**로 만든 짧은 탐험 게임입니다.
빌드 도구 없이 `index.html`만 열면 바로 돌아가는 정적 사이트입니다.

- 바로 열기: `3d/index.html`
- 조작: 화면 왼쪽 드래그(조이스틱) · 바닥 톡 누르기 · 오른쪽 드래그(카메라) · WASD/방향키 · Space(채점)

## 무엇을 하나

1. 크림색 점박이 고양이 **구공이**가 되어 집 안 거실에서 시작합니다.
2. 문을 지나 골목길까지 걸어 다닙니다. (거실 2명 · 골목 4명 = 채점 포인트 6곳)
3. 인간 근처에 가면 **채점하기 · 90점!** 버튼이 뜹니다. 누르면 구공이가 점프하며
   머리 위로 3D `90점` 팻말이 뜨고, 풍자 한마디와 효과음이 나옵니다.
4. 여섯 명을 다 채점하면 오늘의 채점이 끝납니다. (모두 90점, 남은 10점은 인간 몫)

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (타이틀 · HUD · 채점 버튼 · 완료 화면 · 도움말) |
| `style.css` | 크림·브라운 픽셀 감성 UI, 세이프에어리어·가로/세로 대응 |
| `js/main.js` | 게임 루프, 입력(조이스틱·탭·키보드), 3인칭 카메라, 채점 진행 |
| `js/world.js` | 거실·골목길 3D 월드 (창문, 러그, 캣타워, 화분, 문, 우체통, 상자, 가로등, 울타리) |
| `js/cat.js` | 3D 구공이 (점박이 털, 나비넥타이, 90 팻말, 걷기·점프·갸우뚱 애니메이션) |
| `js/npcs.js` | 블록 인형 인간 6명과 소품 |
| `js/gfx.js` | 재질·캔버스 텍스처(나무·돌바닥·러그·90 팻말 등)·점박이 칠하기 |
| `js/audio.js` | Web Audio로 합성한 효과음 (외부 파일 없음) |

## 기술 메모

- Three.js `0.170.0`을 jsDelivr CDN에서 import map으로 불러옵니다. (설치·빌드 없음)
- 모든 텍스처는 런타임 캔버스로 그립니다. 브라우저가 화면 밖 캔버스 메모리를 비워도
  텍스처가 검게 변하지 않도록 한 번 이미지로 구워 둡니다.
- 그림자는 1024 해상도 한 장, 픽셀 비율은 최대 2로 제한해 아이폰에서도 가볍게 돕니다.
- 카메라는 벽에 가리면 레이캐스트로 당겨지고, 걸으면 구공이 뒤로 부드럽게 따라갑니다.
