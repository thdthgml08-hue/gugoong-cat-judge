# 구공이(902) 보안 친구 — 프로토타입

수상한 문자·링크를 같이 봐 주는 침착한 경비원 친구. 데모 모드만 있는 공개 프로토타입이다.

- 주소: `https://thdthgml08-hue.github.io/gugoong-cat-judge/security/`
- 파일: `index.html` · `style.css` · `app.js` · `system-prompt.md`

## 지금 되는 것 (데모 모드)

1. **누르기 전 판별** — 문자 내용을 붙여넣으면 위험도(`위험` / `주의` / `확인 필요`)와 이유 1~2개, 공식 앱에서 직접 확인하라는 안내를 보여 준다. 위험 신호가 없어도 `확인 필요`로 답하고 "안전해"라고 단정하지 않는다.
2. **이미 눌렀을 때** — 화면 닫기 → 있었던 일 5개 선택(복수 선택) → 설치 여부 → 기종(아이폰/안드로이드) 확인 → 기종별 대처(한 번에 한 단계, `다 확인했어`로 확인) → 입력한 정보에 따른 마무리. 기종별 안내를 마친 뒤에야 처음 말한 주소 입력 건으로 넘어간다.
3. **첫 공동 검수 케이스** — `주소도 입력했고 파일도 받았어`를 넣으면 두 가지를 다 기억하면서도 질문은 한 번에 하나만 한다.
4. **선택지 대기 중 다른 입력** — 선택지를 기다리는 중에 새 문자를 붙여넣으면 그 문자를 새로 판별하고, 애매한 입력이면 "아까 질문부터 골라줄래?"라며 선택지를 다시 보여 준다. 판별 뒤에는 "아까 하던 이야기(입력한 정보 확인)도 마저 챙길까?"라며 원래 질문으로 돌아갈 버튼을 보여 준다.

## 안전 규칙 (엔진에 반영됨)

- 비밀번호·인증번호·카드번호·주민번호는 받지 않는다. 입력하지 않아도 된다고 먼저 말한다.
- 링크는 직접 열지 않는다. 주소 모양과 문구만 본다.
- 삭제·초기화·송금은 사용자가 직접 하도록 안내만 한다.
- 증거 보존: 문자·링크는 지우라고 하지 않는다. "문자는 118이나 경찰에 신고할 때 증거가 되니까 지우지 말고, 열지만 마"로 안내한다. 받은 .apk 같은 설치 파일만 열지 말고 삭제하도록 안내한다.
- 모르면 모른다고 말하고 KISA 118 / 112로 연결한다.
- 자책하면 "누구나 속을 수 있어"로 다독인다.

## 다음 단계 (합의안)

공개 화면에는 API 키 입력란을 두지 않는다. 실제 AI 판별을 붙일 때는 키를 서버에 두고 웹앱이 그 서버로 요청하는 구조로 간다. 그때 `system-prompt.md`의 프롬프트를 그대로 쓰면 된다.
